# Magnetic Field Plasma Trap

Parallel implementation(s) of a program for computing magnetic field in a plasma trap.

## Program versions

1. V1: Discrete Fourier Transform, sweep method.
2. V2: Fast Fourier Transform, sweep method.

## Implementations

- `fortran` - original sequential Fortran implementation.
- `cpp` - sequential C++ implementation.
- `mpi` - parallel MPI implementation for distributed memory.

## Build & Install

With CMake or Qt.
